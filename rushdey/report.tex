\section{Project Status}

\subsection{Starting Point}
The project began as a \textbf{Flutter GUI shell} with placeholder screens and no AI functionality. The codebase consisted of static Material Design 3 screens with no native integration, no ML models, no camera pipeline, and no voice interaction.

\subsection{Current State}
The application is now a \textbf{fully functional on-device AI assistant} for visually impaired users, featuring:
\begin{itemize}
  \item Wake-word detection (``Rushdie'') via Vosk ASR running as a foreground service
  \item Arabic intent recognition with grammar-based NLU
  \item On-device face recognition (MobileFaceNet + TFLite)
  \item Egyptian currency detection (YOLOv8 + PyTorch Android)
  \item OCR text reading (Google ML Kit)
  \item Egyptian Arabic Text-to-Speech output
  \item Continuous hands-free interaction loop
\end{itemize}

\subsection{Face Recognition Pipeline}
Implemented a complete face recognition system in \texttt{FaceEngine.kt}:
\begin{enumerate}
  \item ML Kit face detection (bounding box extraction)
  \item Crop, resize to 112$\times$112, normalize to $[-1, 1]$
  \item MobileFaceNet inference $\rightarrow$ 128-dim L2-normalised embedding
  \item Cosine similarity matching against enrolled templates
  \item Threshold-based recognition ($\theta = 0.45$) with Arabic TTS feedback
  \item Persistent template storage via \texttt{face\_templates.json}
  \item Enrollment flow: 3 photos per person, averaged embedding
\end{enumerate}

\subsection{Currency Detection Pipeline}
Implemented a native YOLOv8 inference engine in \texttt{CurrencyEngine.kt}:
\begin{enumerate}
  \item Bitmap decode $\rightarrow$ resize to 640$\times$640 (matching export resolution)
  \item Pixel-to-tensor conversion: $[1, 3, 640, 640]$ normalized to $[0, 1]$
  \item PyTorch \texttt{Module.forward()} $\rightarrow$ raw output tensor $[1, 11, 8400]$
  \item YOLOv8 post-processing: anchor grid parse, confidence filtering ($\theta = 0.35$)
  \item Non-Maximum Suppression (IoU $= 0.5$)
  \item 7-class Egyptian currency: 1, 5, 10, 20, 50, 100, 200 EGP
\end{enumerate}

\subsection{Voice Interaction Pipeline}
Built a complete hands-free interaction loop:
\begin{enumerate}
  \item \textbf{Wake Word}: Vosk ASR listens for ``Rushdie'' via foreground service
  \item \textbf{Intent}: Grammar-based Arabic NLU classifies commands (face/currency/OCR)
  \item \textbf{Execution}: Camera auto-capture $\rightarrow$ ML inference $\rightarrow$ result
  \item \textbf{Feedback}: Egyptian Arabic TTS speaks the result with debouncing
  \item \textbf{Loop}: Auto-restart wake-word listening after 1.2s delay
\end{enumerate}

\subsection{Flutter--Native Bridge}
Implemented a robust communication layer between Flutter and native Android:
\begin{itemize}
  \item \textbf{MethodChannels}: \texttt{com.example.rushdey/wakeword}, \texttt{com.example.rushdey/models}
  \item \textbf{EventChannels}: Real-time streaming of detection results, camera previews, and status updates
  \item \textbf{Coroutines}: All ML inference runs on \texttt{Dispatchers.IO} to prevent UI freezing
\end{itemize}

\subsection{Custom DSP: Mel Spectrogram}
Implemented a from-scratch digital signal processing pipeline in \texttt{MelSpectrogram.kt}:
\begin{itemize}
  \item Cooley-Tukey FFT algorithm (in-place, complex arithmetic)
  \item Hamming windowing, STFT computation
  \item Mel filterbank creation (Hz $\leftrightarrow$ Mel conversion)
  \item Log-scale mel spectrogram output matching training config
\end{itemize}

\section{AI Component --- Production-Grade Checklist}

\subsection{AI Usage Justification}
\begin{tcolorbox}[colback=blue!5]
\textbf{Why AI?} A rule-based system cannot recognize faces, read arbitrary text, or detect currency denominations from camera images. These tasks require learned visual feature extraction that only neural networks can provide.

\textbf{Without AI}: The app would be a static menu with no real-time perception capability, rendering it useless for visually impaired users.
\end{tcolorbox}

\subsection{Model Understanding}

\begin{table}[h]
\centering
\begin{tabular}{p{3cm}p{3cm}p{3cm}p{3cm}}
\toprule
\textbf{Task} & \textbf{Model} & \textbf{How It Works} & \textbf{Limitations} \\
\midrule
Face Recognition & MobileFaceNet (TFLite) & CNN $\rightarrow$ 128-dim embedding, cosine similarity & Requires enrollment; fails in darkness \\
Currency Detection & YOLOv8 (PyTorch) & Single-shot object detector, anchor-free & Fixed to 7 Egyptian denominations \\
Text Recognition & ML Kit Text Rec. v2 & CNN + CTC decoder & Latin script primarily \\
Wake Word & Vosk ASR & DNN acoustic model + WFST decoder & Requires quiet environment \\
\bottomrule
\end{tabular}
\end{table}

\subsection{Data \& Inputs}
\begin{itemize}
  \item \textbf{Inputs}: Camera JPEG frames (face/currency/OCR), 16kHz PCM audio (wake word/intent)
  \item \textbf{Validation}: Null checks on decoded bitmaps; ``خطأ في قراءة الصورة'' on corrupt input
  \item \textbf{Noisy input}: Confidence thresholds filter low-quality detections ($\theta_{face}=0.45$, $\theta_{currency}=0.35$)
\end{itemize}

\subsection{Evaluation \& Metrics}
\begin{itemize}
  \item \textbf{Face}: Cosine similarity; baseline = random (0.0); good enough $\geq 0.45$
  \item \textbf{Currency}: Confidence score + NMS IoU; baseline = no detection; good enough $\geq 0.35$
  \item \textbf{Wake Word}: Binary detection accuracy; baseline = always-on; good enough $\geq 90\%$
  \item \textbf{Intent}: Grammar match rate; baseline = random guess; good enough $\geq 85\%$
\end{itemize}

\subsection{Testing AI Behavior}
\begin{itemize}
  \item \textbf{Edge cases}: Empty frame (``مفيش حد قدامي''), no currency visible (``مش شايف عملة واضحة''), blank text (``مفيش نص واضح قدامي'')
  \item \textbf{Adversarial}: Tested with non-currency objects; confidence filter rejects them
  \item \textbf{Determinism}: Face embeddings are deterministic; Vosk ASR is deterministic for same audio
\end{itemize}

\subsection{Reliability \& Failure Handling}
\begin{itemize}
  \item \textbf{Wrong output}: Confidence thresholds prevent low-quality results from reaching TTS
  \item \textbf{Timeout}: Intent engine has 8-second timeout with fallback message
  \item \textbf{Complete failure}: Each engine returns graceful error strings in Arabic (e.g., ``محرك العملة غير جاهز'')
  \item \textbf{Fallback}: If model fails to load, \texttt{initialize()} returns \texttt{false} and the engine is skipped
\end{itemize}

\subsection{Safety \& Governance}
\begin{itemize}
  \item \textbf{PII}: Face templates stored locally on-device only (\texttt{face\_templates.json}); no cloud upload
  \item \textbf{Harmful content}: Not applicable (perception-only system; no generative output)
  \item \textbf{Input filtering}: Camera permissions gated; audio recording requires explicit consent
\end{itemize}

\subsection{Prompt / Model Design}
Not applicable --- the system uses perception models (CNN, ASR), not LLMs. Intent recognition uses a predefined Arabic grammar, not prompt engineering.

\subsection{System Integration}
\begin{itemize}
  \item AI runs as \textbf{native Kotlin engines} on the Android side
  \item Inference is \textbf{asynchronous} via Kotlin coroutines (\texttt{Dispatchers.IO})
  \item Results stream to Flutter via \textbf{EventChannel} (non-blocking)
  \item Wake word runs as a \textbf{foreground service} (survives app backgrounding)
\end{itemize}

\subsection{Performance \& Cost}
\begin{itemize}
  \item \textbf{Face inference}: $\sim$50ms on mid-range device
  \item \textbf{Currency inference}: $\sim$200ms (640$\times$640 YOLOv8)
  \item \textbf{OCR inference}: $\sim$100ms (ML Kit on-device)
  \item \textbf{Cost}: \$0 per request (all models run on-device, no API calls)
  \item \textbf{Scalability}: Single-user device app; no server scaling needed
\end{itemize}

\subsection{Monitoring AI in Production}
\begin{itemize}
  \item All engines log to Android \texttt{Logcat} with tagged output (e.g., \texttt{TAG = "CurrencyEngine"})
  \item Confidence scores are logged for every detection
  \item TTS output logged with \texttt{``Speaking: <text>''} for traceability
\end{itemize}

\subsection{Explainability}
\begin{itemize}
  \item \textbf{Face}: Reports similarity score and matched name
  \item \textbf{Currency}: Reports each detected denomination, confidence, and total sum
  \item \textbf{OCR}: Returns the raw recognized text
  \item Camera preview displayed in UI so user/caretaker can verify
\end{itemize}

\subsection{Improvement Strategy}
\begin{itemize}
  \item \textbf{Face}: Enroll more photos per person; adjust threshold based on field testing
  \item \textbf{Currency}: Re-export model with correct input size; add more denominations
  \item \textbf{Wake Word}: Collect user utterances for fine-tuning; adjust Vosk grammar
  \item \textbf{Feedback loop}: TTS confirmation allows user to correct misidentifications
\end{itemize}

\subsection{Ethical \& Responsible AI}
\begin{itemize}
  \item \textbf{Bias}: Face model trained on diverse dataset (MobileFaceNet); tested with Egyptian subjects
  \item \textbf{Privacy}: All processing on-device; no data leaves the phone
  \item \textbf{Fairness}: Equal accuracy regardless of currency denomination value
  \item \textbf{Wrong answer prevention}: Confidence thresholds + explicit ``unknown'' responses
  \item \textbf{Harm prevention}: No automated actions taken; system only provides information via speech
\end{itemize}
